# Lukas Deemer — Portfolio

**Live site:** [mixer-lukas1950.github.io](https://mixer-lukas1950.github.io)

Personal portfolio for Lukas Deemer, a filmmaker, actor, and editor from Latrobe, PA, studying Theatre at Allegheny College with minors in Software Engineering and Filmmaking.

## What's on the site

- **Featured film:** *Egg*, an 11.5-minute psychological thriller
- **Film & Acting:** short films (*Egg*, *S.T.P.*, *TERMINALITY*), stage credits, and a downloadable résumé
- **Video Editing:** tools and editing experience
- **YouTube:** short films from [@Lukas1950](https://www.youtube.com/@Lukas1950)
- **Contact:** message form and links to YouTube, Backstage, Casting Call Club, and Instagram

## Built with

- [Astro](https://astro.build) for pages and layout
- HTML and CSS, with a light/dark theme toggle written in React
- GitHub Pages, deployed automatically through GitHub Actions on every push to `main`

This site started as a project for CMPSC 302 (Web Design) at Allegheny College and has since been rebuilt as my working portfolio.

## Run it locally

```bash
npm install
npm run dev
```

Then open `http://localhost:4321`.
